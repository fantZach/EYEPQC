# 开发板安装与使用：正式版第一版

适用于领航者 **CF7020B**、OV5640 摄像头、Windows 电脑。
本版从 SD 卡启动，日常不用 JTAG 下载器，电脑运行 `eyepqc run`。
用户已反馈本次版本正常连接；其他未做的测试仍需分别验收。

## 1. 准备材料

- 开发板、电源、OV5640 摄像头。
- 可正常读写的 FAT32 SD 卡、读卡器、能传数据的 USB 线。
- 按 [PC 教程](../pc/DEPLOYMENT.md) 配置好的电脑程序、账号与手机 APP。
- 本版 `BOOT.BIN`，以及与配对信息匹配的三份私有文件：

| 文件 | 用途 |
|---|---|
| `BOOT.BIN` | 开发板启动程序 |
| `EYEKEY.BIN` | 板卡身份文件 |
| `EYERNG0.BIN`、`EYERNG1.BIN` | 板卡自动更新的随机状态 |

四个文件最终都放在 **SD 卡根目录**。
公开程序包不含三份私有文件；首次安装请让安装负责人在可信电脑上准备，并核对配对信息。
不要把私有文件发到聊天、日志或公开仓库。已有身份继续复用，不因升级重新生成。

## 2. 写卡：已有正常运行卡跳过

**卡上已有三个私有文件且能正常使用时，跳到第 4 节。升级只更新匹配的 BOOT，不覆盖身份和随机状态，不恢复旧状态备份。**

1. 手机点“停止”；电脑服务窗口按 **Ctrl+C**，等待退出。
2. 关闭板卡 **K1**，确认核心板灯全灭，再取卡。灯仍亮时先断开可能反向供电的 USB、JTAG 或调试线，不能带电拔卡。
3. SD 卡接电脑。在“此电脑”右键该盘、打开“属性”，核对盘符、容量与 FAT32。不要照抄以前的盘符，也不要格式化现有卡。
4. 若卡上已有任意 `EYEKEY.BIN`、`EYERNG0.BIN`、`EYERNG1.BIN`，停止复制，交安装负责人核对，不点“全部替换”。
5. 有旧 `BOOT.BIN` 时，先备份到电脑的新文件夹，再将卡内旧文件改成不重复的备份名；不删除历史备份。
6. 将新 `BOOT.BIN` 和三份已准备的私有文件复制到卡根目录，等待完成。不要只复制压缩包或放进子文件夹。
7. 请安装负责人核对启动文件与交付清单相符，以及三份私有文件的写入内容一致。

## 3. 重插读卡器，确认保存成功

1. Windows **安全弹出** SD 卡。
2. 将整个读卡器 USB 插头拔下，再接回电脑，SD 卡留在读卡器内。
3. 确认是同一张卡、四个文件仍在根目录，请安装负责人再次核对内容。

若文件变化、复制报错或容量为 0，停止使用，保留现场排查；不要反复覆盖、自动修复或格式化。
板卡运行后，两个状态文件会变化，不能再要求它们与最初准备的文件相同。

## 4. 接线与上电

1. 安全弹出 SD 卡；板卡 **K1 关闭、核心板灯全灭**时，将卡插回板卡。
2. 摄像头接 **P2**，摄像头插拔同样要完全断电。
3. 本项目已确认的 CF7020B：`BOOT_CFG` 两位均为 **OFF，远离 ON 标识**。不同板卡版本先查说明，不猜拨码。
4. 拔掉 JTAG。用数据线连接板卡 **USB Slave / P4** 与电脑，确认处于从机模式；不用连接 PS 网口。
5. 打开 **K1**，等待启动。调试串口可以保留，但要注意反向供电。

在电脑设备管理器中找到视频 USB 串口。历史编号为 **COM7**，调试串口为 **COM4**，实际以当前显示为准，不要混用。

## 5. 启动服务，在手机观看

第一次使用或更换 USB 接口后，设置实际的视频串口。例如设备管理器显示 COM7：

```powershell
eyepqc config set serial_port COM7
eyepqc check
eyepqc run
```

本版不加 `--dev-usb-bootstrap` 或 `--dev-identity-file`。不要同时启动两份服务。
看到 `PC_RUNNING` 后，手机填写已配置的服务地址、用户名和密码，点击连接；无需手动导入 JSON。

确认成功：画面持续变化、“认证帧”持续增加；再试停止重连和手动换钥，视频应能恢复。
电脑提示服务启动、板卡灯闪烁，都不能单独证明手机视频正常。

## 6. 常见问题

| 现象 | 先做什么 |
|---|---|
| 只有调试串口，没有视频串口 | 检查供电、Slave 模式、P4、数据线和驱动，不改用调试串口凑数 |
| 提示串口或端口占用 | 正常退出自己之前启动的服务或占用串口的软件，不盲目结束其他进程 |
| 板卡未就绪、`G6_SD_IDENTITY_FAIL` | 保存错误，检查本版 BOOT、三个文件是否齐全、卡是否可写，不恢复旧状态 |
| 登录或证书错误 | 按 PC 教程核对账号、地址与证书，不关闭证书校验 |
| 提示身份或指纹改变 | 请安装负责人核对卡上身份与配对信息，不删除手机信任记录绕过错误 |
| 连接异常、画面停止 | 记录每次结果、APP 状态和电脑错误，交维护者排查，不反复重刷 |

状态文件损坏时由安装负责人准备新的随机状态，不能从旧备份恢复后继续使用。
本版首次材料配置端仍须可信；详细限制、构建与旧版操作见 [高级教程](DEPLOYMENT_ADVANCED.md) 和 [SD 身份说明](../doc/g6_sd_identity.md)。
