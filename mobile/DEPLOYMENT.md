# Android：安装后连接观看

这是项目正式第一版的手机操作教程。本仓库可构建的 APK 组件编号为 `0.9.0-rc1`（versionCode 9），支持 Android 8.0 及以上；项目交付名称不改变 APK 的签名或程序版本。已安装且能正常播放的 APP 可继续使用，本次教程不强制更换。

## 1. 安装 APK

1. 从负责人提供的可信位置取得**可安装 APK**，核对交付清单中的 SHA256。不要安装来历不明的同名文件。
2. 将 APK 传到手机，点击安装；系统询问时，只对当前用于打开 APK 的应用允许“安装未知应用”。
3. 已有 APP 优先直接覆盖安装。升级要求包名、签名相同且 versionCode 不降低；签名不同时先联系负责人，避免直接卸载丢失已保存的板卡指纹。

本次可安装调试包沿用原 Debug 签名，不冒充商业发布签名；`release-unsigned.apk` **未签名，不能安装**。
自行构建、正式签名或更换信任 CA，见[高级部署说明](DEPLOYMENT_ADVANCED.md)。

## 2. 连接前准备

请负责人先完成板卡启动、Windows PC 服务及公网隧道配置。手机用户需要这两项：

| 内容 | 从哪里取得 |
|---|---|
| 可信服务地址 | 当前示例为 `wss://203.0.113.10:8765/stream`；使用负责人实际提供的地址 |
| 用户名、密码 | PC 管理员创建；不是服务器 SSH 的账号密码 |

当前调试 APK 的专用测试 CA 于**北京时间 2026-11-13 00:59**到期，负责人需提前协调更新 PC 证书和 APP 的 CA 信任。

## 3. 登录并观看

1. 打开 EYEPQC，展开“连接设置”，确认服务地址正确。
2. 输入用户名和密码，点击“连接并观看”。
3. APP 自动下载并导入公开 `pairing.json`，与板卡协商视频密钥，成功后显示视频及 FPS。**无需手动填写 JSON、token 或私钥。**

首次配对依赖已验证的 HTTPS 服务；已有配对时会检查保存的板卡指纹。
若提示板卡身份变化，先向负责人核对，不能通过清除应用数据绕过。
若另一设备正在观看，只有确认接管才会关闭旧连接；不同用户名仍共享一块板卡的单观看能力。

## 4. 停止、重连和换钥

- **停止观看**：点“停止”，等待状态显示已停止；需要时再点连接。
- **手动换钥**：在播放页点击换钥，短暂停顿后应恢复视频。
- **自动换钥**：约每 30 分钟自动重新握手，不更换账号或固定板卡身份。
- APP 离开前台会断开并清除画面，返回后重新连接；当前不提供后台播放。

## 5. 连不上时先看提示

| 提示或现象 | 处理 |
|---|---|
| 证书校验失败 | 检查手机时间；让负责人核对证书有效期、地址和 APP 信任 CA，不改用明文 WS |
| 账号或密码错误 | 让 PC 管理员核对账号或重设密码，不发送密码截图 |
| 网络连接超时 | 让负责人确认 PC 服务、服务器 22022 隧道与 8765 视频端口 |
| 握手超时、认证失败 | 记录时间及 APP 提示，交给负责人对照 PC/板端日志 |
| 已保存的板卡身份变化 | 核对是否确实更换身份，按可信配对流程迁移 |

验收时记录登录、首次连接、停止后重连、手动换钥及显示帧率即可；更完整的证书、接管和故障验收见[高级说明](DEPLOYMENT_ADVANCED.md#7-用户统一验收记录)。
