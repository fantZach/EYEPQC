# 当前进度

## 正式版第一版：2026-10-31

用户确认当前 SD 本地身份版正常连接，并指定为正式版第一版；此前首次连接失败的问题也由用户反馈已修复。
本次仓库整理没有新增硬件、手机或公网测试，没有覆盖既有 GitHub v1.0.0 标签或上传新附件。

- 开发板：固定身份与双槽随机状态保存在 SD；日常 PC 不再注入私钥/seed。
- PC：`eyepqc run`，账号、WSS、USB 密文转发及可选 SSH 中转。
- Android：登录后自动获取公开配对信息，握手、换钥、认证解密与视频显示。
- Server：受限 SSH 透明 TCP 中转，不持有业务视频密钥。

当前来源、软件测试和准确产物范围见 [SD 实现记录](sd_local_identity_20261031.md)、[写卡记录](sd_local_deployment_20261031.md) 和 [正式版记录](../doc/releases/first-stable.md)。
原新手部署入口及四端高级教程保留；过时调试、协调、阶段候选和 P2P 试验文档已移出源码，原文留在维护者本机忽略目录。
实际服务器地址、专用 SSH 端口、个人路径和设备标识已从当前文档示例脱敏；示例不能直接当成可连接的部署地址。

## 验收与限制

用户反馈是本次连接可用证据，没有新增精确 FPS 测量。冷启动、拔插、自动换钥、故障及长稳仍按各自实际证据分别验收。
历史 G0 十分钟例外、G7 约五十分钟例外不改成三十分钟或满两小时实测，不顺带关闭故障子项。
首次材料配置端仍须可信，没有硬件熵、受保护存储或 SD 快照回滚保护。
证书更新与信任有效期见 [TLS 记录](tls_renewal_20261031.md)，账号和部署见 [四端教程](../doc/deployment/README.md)。
