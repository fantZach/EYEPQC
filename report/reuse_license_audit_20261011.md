## 发布前仍需的决策与检查

1. 由团队确认谁拥有自研源码、文档和素材的权利，以及是否同意公开再分发；多人共同创作时应覆盖所有必要权利人。
2. 取得 AMD FPGA 创新赛道适用的最新官方提交/开源要求，确认是否必须公开、推荐/允许的许可证和代码范围。
3. 逐文件核查源代码头、上游版本、修改范围和运行时包含关系；保留必要的 LICENSE/NOTICE，不将工具链生成物或厂商文件未经核验地打包。
4. 完成公开前敏感数据检查：测试密钥、seed、provision 输入、个人路径/资料、USB/串口原始载荷、私有构建产物和未授权照片/录像。
5. 只有完成权利确认和审查后，才由权利人决定项目级 LICENSE 及仓库公开范围。

本次仅做了只读盘点；没有新增项目级许可证、没有更改 GitHub 仓库可见性，也没有把本机忽略的构建/测试数据加入提交。
