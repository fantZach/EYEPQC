# EYEPQC——基于后量子密钥协商的单向视频加密系统

EYEPQC 面向 Zynq-7020 开发板，实现摄像头 JPEG 视频的单向加密传输与主机端认证显示。系统由 OV5640 摄像头采集 JPEG；PS 端运行 ML-KEM-512 会话握手、密钥派生与 USB CDC 控制/传输管理；PL 端完成 AES-128-GCM 加密。主机收到视频分片后先验证认证标签，再重组、解密并解码 JPEG。视频只从板端发送到主机，少量握手与控制消息支持双向通信。

项目已完成固定 DDR/DMA 加密、实拍 JPEG 连续采集、USB 实时视频、AES-GCM 篡改拒绝及开发态 ML-KEM 动态握手等功能验证。实测 G4 明文视频约 47.258 fps、G5 加密视频约 47.270 fps；G6 双会话换钥、握手篡改拒绝和 DTR 逻辑重连通过。证据、复现步骤和指标边界见 [项目进度](../report/progress.md)、[G4/G5 板测](g4_g5.md) 与 [G6 板测](g6.md)。

当前结果属于功能原型，不应描述为已完成产品级安全验收：G6 使用 JTAG 注入的开发测试密钥和种子，生产级可信熵源、密钥保护及侧信道评估尚未完成；G0 整机门禁和 G7 实际拔线、摄像头异常、DMA 超时等故障项仍待验收。G7 原两小时长测按用户决定获时长豁免，已核实的实际运行约 50 分钟。项目状态以进度文档中的验收记录为准。
