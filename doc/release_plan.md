# 四端调试完善与正式交付计划

更新：2026-10-31。用户决定：**验收由用户统一进行**。开发侧负责实现、软件回归、候选打包和详细教程，
不自行操作板卡/手机/现网来替代用户验收，也不把历史测试移植为新版本通过。

本轮四端本机候选已准备，集合编号 `v1.1.0-rc1`；完成内容、测试和固定包 hash 见
[候选交付记录](../report/candidate_20261031.md)。Android 的真实长期签名材料未指定，release 仍为 unsigned，
所有用户验收仍 pending；因此这不是四端正式稳定版已经发布的声明。

## 交付目标

保留已经发布的 v1.0.0，不覆盖标签、包或历史证据。下一阶段先完成四端可独立部署的候选交付，
由用户对同一组固定哈希验收后，再选择新版本号发布正式稳定版。

“正式交付”指版本明确、可安装/配置/启动/维护、可备份回滚、有部署和故障排查教程；
不等于硬件生产安全认证。原 SD/USB 开发态由可信 PC 提供测试身份/seed，这一模型不会因去掉 debug 标志而变成生产密钥方案。
新增 [SD 本地身份模式](g6_sd_identity.md) 可取消日常 PC 注入，但首次配置端仍可信，不新增硬件熵或防卡快照回滚能力；两个配置各自验收。

| 部分 | 本轮优先改进 | 交付要求 |
|---|---|---|
| Board | 复用最终生成代码/清单校验，提供最小本机候选包 | BOOT、脱敏清单、哈希、教程及必要许可；默认用户待验，不自动写卡 |
| PC | 程序安装与运行材料分离，全新电脑可先安装，再安全初始化/配置 | CLI、用户级安装器、完整许可、安装/材料/账号/升级回滚教程 |
| Android | 非 debuggable release 构建、外部持久签名材料、显式专用 CA | 可验证签名的安装包；无真实签名材料时仅 unsigned，不能冒充可安装正式包 |
| Server | 独立源码/模板交付、部署前检查、服务维护与回滚说明 | 不含真实授权文件或 host 私钥的包；真实 sshd/systemd/公网由用户验收 |

## 已确定的部署条件

- 开发板：CF7020B / XC7Z020，OV5640；SD 启动，USB Slave 接 Windows PC。
- 移动端：Android。继续连接公网 **124.70.38.245**，暂时没有域名。
- 云端仅提供 OpenSSH 反向 TCP 中转；业务 TLS、账号和登录验证仍在 PC。
- 手机账号模式为 WSS / schema2 / suite2，自动下载公开配对，不恢复旧 token、明文 WS 或手工复制私钥流程。
- Android 正式候选需显式信任部署者选择的公开 CA，证书叶子 SAN 必须匹配该 IP；
  仍校验链、地址和有效期，不使用 trust-all。旧调试 CA 到期时间为 2026-11-12 16:59:03 UTC。

## 开发顺序

1. 各端修复交付缺口、补失败用例和定向回归，冻结 schema2/suite2 与 EYBS v1 接口。
2. 提供逐端部署教程及共同材料清单，明确哪些文件可以复制、哪些只保留在可信本机。
3. 离线生成候选、核对文件集合/版本/哈希/许可，所有验收字段保持 `pending`；不发布为稳定版。
4. 用户按 [统一部署入口](deployment/README.md) 配置，并提交 [统一验收记录](deployment/ACCEPTANCE.md)。
5. 只针对用户报告的实际失败修复并重新冻结受影响候选，不把旧版本结果当作新版结果。
6. 用户确认通过后，再按固定版本/提交/哈希发布四端正式包及部署教程。

## 不在本轮静默变更的内容

- 不连接云端部署、不启动/停止真实 PC 服务、不碰 SD/JTAG/USB、不更改真实账号或证书。
- 不自动生成或替换 Android 正式签名身份、CA 信任根、板端身份、SSH host key；不得将秘密打包。
- 不以自动重试掩盖 USB 首次 QUERY 超时，不放宽半包/FAULT/重放/Tag/账号检查。
- 不新增付费服务、域名、代码签名采购，不更改仓库可见性或擅自决定统一开源许可。

## 正式版仍需的明确前置

- 用户保存并选择持久的 Android release keystore/alias，安全备份密码；签名密码不进命令行或仓库。
- 部署用 CA/叶证书及 TLS 私钥由部署者管理；公开 CA 可给 APP，CA 私钥不能随 PC 服务或 APK 分发。
- 本机受保护的板端测试身份与公开配对一致；服务器 SSH host 指纹需独立核验。
- Board 含 AMD 生成物的候选默认仅本机自验使用，外部分发范围仍须权利人核实，不能把本机打包当作许可批准。
- 真实冷启动、首连/重连、视频、换钥、故障、安装升级等通过与否，由用户提交的新版本记录决定。
