# 用户统一验收记录模板

复制本表到自己的本机记录，再填写；本模板所有项目默认 **待验收**，不代表通过。
请只回传脱敏结果/错误类型/统计，不发送密码、私钥、seed、登录 Authorization 或完整敏感抓包。

## 固定版本

| 项目 | 用户填写 |
|---|---|
| 日期/时区、操作者 | 待填 |
| 源码 commit / 候选编号 | 待填 |
| Board 包与 BOOT SHA256 | 待填 |
| PC CLI/安装器版本及 SHA256 | 待填 |
| Android 版本/APK SHA256/签名证书指纹 | 待填 |
| Server 包 SHA256、Linux/OpenSSH 版本 | 待填 |
| 手机型号/Android、Windows 版本 | 待填 |
| 公网端点与 CA/SSH host 公共指纹 | 待填，不填任何私钥 |
| 板端公开身份 SHA256 pin | 待填，不填私钥或 seed |

## 分项结果

每项记录“通过/失败/未执行”、时间和脱敏证据文件名；不能以旧版本证据补填新版本。

| 组别 | 操作/观察 | 结果 |
|---|---|---|
| PC 安装 | 全新用户环境只装程序，无材料也可完成安装；缺材料 `check/run` 明确拒绝，不启动服务 | 待验收 |
| PC 初始化 | 受保护目录/首账号创建，重复初始化不覆盖；密码不回显 | 待验收 |
| PC 维护 | 账号增改删、最后账号保护；正常重启后生效；既有数据升级/卸载不丢失 | 待验收 |
| Server | 实际 sshd -t/-T、权限、服务状态；管理 SSH 不变；错误 key/用户/shell/越权转发拒绝 | 待验收 |
| TLS/APP 安装 | 正式签名及非 debuggable；正确 IP/证书链登录，错误地址/过期/不可信证书拒绝 | 待验收 |
| SD 冷启动 | 保留旧 BOOT；无 JTAG、确实全断电后上电；记录 UART boot_mode、WAIT/READY | 待验收 |
| USB 首连 | 从新冷启动首次打开/查询/观看，记录是否超时；不要只记录第二次成功 | 待验收 |
| 正常视频 | 认证帧前后计数、约定时长、帧率、缺片/丢帧统计，手机画面正常 | 待验收 |
| 重连 | APP 正常停止/重连、PC 正常退出重启，USB 和账号归属释放 | 待验收 |
| 换钥 | 手动换钥、实际跨 30 分钟自动重握手，画面恢复且旧画面不残留 | 待验收 |
| 账号冲突 | 错误密码拒绝；同账号显式接管、取消接管；不静默踢人/抢占 | 待验收 |
| APP 生命周期 | 横竖屏、全屏/返回、切后台停止/清画面、网络失败提示 | 待验收 |
| 故障 | 按步骤规定的 USB/相机/断网故障分别记录；不把正常 STOP 当故障测试 | 待验收 |
| 更新回滚 | 保留旧签名/配置/镜像/哈希，按教程回退；注意不同签名 APK 的数据迁移 | 待验收 |

持续时长以真实记录为准；若有例外，写明实际时长和批准人，不把约 50 分钟改记为实际两小时。

## 总结

- 失败项与稳定复现步骤：待填。
- 本次明确未执行的项目：待填。
- 是否接受此固定候选作为正式发布基线：**待用户确认**。
- 用户确认范围/日期：待填。

该确认不等于生产安全评估通过；熵源、长期身份、可信启动/JTAG 防护等仍按独立安全前置处理。
