# 正式版第一版：部署从这里开始

适用于 2026-10-31 确认可用的版本：开发板从 SD 启动，Windows PC 转发，Android 手机观看，公网服务器中转。

## 已能看视频？每天只做三步

1. SD 卡留在板上，接好摄像头和 USB Slave 视频线，给板卡上电。
2. 电脑打开 PowerShell，输入 `eyepqc run`，保持窗口打开。
3. 手机打开 APP，输入账号密码，点击连接。

结束时先在手机停止，再在电脑窗口按 `Ctrl+C`。本版不再需要两个 `--dev-*` 参数。

## 第一次安装

准备开发板、摄像头、SD 卡及读卡器、Windows 电脑、Android 手机；外网观看还需有公网 IP 的 Linux 服务器。

| 顺序 | 教程 | 做什么 |
|---|---|---|
| 1 | [开发板](../../board/DEPLOYMENT.md) | 准备 SD、接线、上电 |
| 2 | [Windows PC](../../pc/DEPLOYMENT.md) | 安装程序、配置连接、创建账号 |
| 3 | [公网服务器](../../server/DEPLOYMENT.md) | 配置外网中转 |
| 4 | [Android 手机](../../mobile/DEPLOYMENT.md) | 安装 APP、登录看视频 |

局域网观看可跳过服务器，但仍需与连接地址匹配的证书和手机信任配置。

安装包不包含你自己的密码和私钥。首次安装由安装负责人准备板卡文件、PC 配置与证书、公开配对信息、SSH 文件和匹配的可安装 APK。
如果由你负责全新部署，每份教程都提供对应的进阶操作入口；日常使用不需要重新生成这些文件。

## 常见问题

| 现象 | 先做什么 |
|---|---|
| 找不到 `eyepqc` | 关闭所有终端窗口，再重新打开 |
| 端口已占用 | 在原来的服务窗口按 `Ctrl+C`，不要重复启动 |
| 手机连接超时 | 看电脑是否出现 `PC_RUNNING`，再按服务器教程检查 |
| 证书错误 | 请安装负责人更新证书，不关闭校验 |
| 登录失败 | 核对用户名，按 PC 教程重设密码 |
| 没有画面 | 检查供电、摄像头、USB Slave 视频线和视频串口 |
