# M03：DVP/JPEG 字节采集

用户要求按 `steps` 推进。Ponytail 复用现有 Icarus、Vivado 和标准库，不加入临时 BRAM 快照、
主机依赖或 DMA/网络框架；真实摄像头图片已在后续 M05 集成中保存，证据见 [M05](m05.md)。

## 接口与边界

`dvp_capture.sv` 在 PCLK 上升沿采样 VSYNC/HREF/D[7:0]；HREF 仅限定有效字节，不定义帧结束。
`capture_resetn` 接 M02 配置成功信号，异步断言、两级同步释放；PCLK 停止时也会立即清除输出。
复位后忽略当前残帧，观察到 VSYNC 有效区间后才接收下一物理帧。
HREF/VSYNC 默认高有效，可通过参数调整；实际极性、采样边沿与 PCLK/IO 时序仍需实测。
所有输出/计数器在 PCLK 域，跨域与原子读回属于 M04，不直接给 PS/100 MHz 使用。

`jpeg_marker_check.sv` 接有效字节和物理帧边界，默认最大帧长 2097152 字节（含 SOI/EOI）。
输出 `byte_out/byte_valid`；`frame_start` 与 SOI 的 FF 同周期，`frame_end` 与 EOI 的 D9 同周期。
一字节流水线保留 SOI 前缀，无论标记是否跨 HREF 间隙，均保留原始字节且每周期最多输出一字节。
`frame_length` 在结束/错误时更新并保留，`error_flags` 保留最后一次故障，`frame_error` 是脉冲。
异常嵌套 SOI 可同周期产生 `frame_error/frame_start`：下游必须先丢弃旧帧，再接收新帧的 FF。

| error_flags 位 | 故障 | 独立计数器 |
|---|---|---|
| 0 | 物理帧有字节但没有 SOI | missing_soi |
| 1 | 已开始 JPEG 但缺少 EOI | missing_eoi |
| 2 | 未完成 JPEG 就出现 VSYNC | unexpected_vsync |
| 3 | 无有效字节，或 SOI/EOI 间没有扫描段 | empty_frames |
| 4 | 超过最大帧长 | oversize_frames |
| 5 | 非法标记/段长度或异常嵌套 SOI | marker_errors |

同时保留 `frames_captured/frames_dropped`，计数器按 32-bit 回绕；组合错误可增加多个分类计数。
转发字节是暂定数据，直到合法 EOI 才算一帧通过；遇到错误不得把已转发的半帧保存/显示。
M04 必须处理溢出/丢帧与帧错误，M05 再管理 DDR 所有权；本模块没有整帧存储或背压。

帧标记检查按段长度跳过 APP/COM/量化/扫描头等载荷，避免段内 FF D8/FF D9 被误判。
扫描数据保留 FF00 转义、restart 和 fill 字节；只检查帧边界/长度，不解码或校验量化/Huffman/像素。
格式事实交叉核对 [libjpeg-turbo 上游标记读取](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/main/src/jdmarker.c)，未复制其实现。

## 复现

```powershell
& ./.venv/Scripts/python.exe sim/tb/test_m03.py
# 可选：用本地真实 JPEG 作为输入激励；不是摄像头实拍。
$env:M03_REAL_JPEG='D:/pictures/test.jpg'
try { & ./.venv/Scripts/python.exe sim/tb/test_m03.py }
finally { Remove-Item Env:M03_REAL_JPEG }
# 新输出目录；仅独立模块 OOC 综合，不下载板卡。
& 'D:/AmdDesignTools/2026.1/Vivado/bin/vivado.bat' -mode batch -source prj/check_m03.tcl -log build/m03_synth_demo.log -journal build/m03_synth_demo.jou -tclargs build/vivado/m03_synth_demo
```

覆盖 HREF 间隙、EOI 紧邻 VSYNC、帧前噪声/帧后尾部、缺少 SOI/EOI、截断、空帧、
非法段长度、嵌套 SOI、FF00/restart/fill、恰好达到/超过上限、错误统计与下一帧恢复、
正反 HREF/VSYNC 极性、PCLK 停止期间复位。额外 APP/COM 假标记真 JPEG 的 4 帧也通过。
