# 正式版第一版

2026-10-31，用户确认当前 SD 本地身份版本能连接播放，并指定为正式版第一版。
该基线以 [v1.1.0](v1.1.0.md) 交付，不覆盖已有 GitHub `v1.0.0` 标签或附件。

## 功能

- 板卡从 SD 启动，卡上保存固定身份私钥及更新的随机状态。
- PC 使用 `eyepqc run`，负责账号、USB 与网络转发，运行时不注入板端秘密。
- Android 自动配对、握手、换钥、解密播放；服务器透明中转。
