# EYEPQC v1.1.0 — 正式版第一版

SD 启动、Windows 转发、Android 解密观看的四端版本。用户已确认当前部署正常连接，并反馈首次连接问题修复。

## 下载后怎么用

| 附件 | 内容 |
|---|---|
| Board Source | 板端源码、构建入口和教程；不含预编译 BOOT |
| Windows PC | PC 1.4.0 命令行程序、安装器及教程 |
| Android | 0.9.0 可安装 Debug APK、安装教程及许可 |
| Server | 1.0.0 中转服务源码及部署教程 |

从 [四端新手教程](../deployment/README.md) 开始，下载后用 `SHA256SUMS.txt` 核对文件。
已有正常部署日常操作不变：板卡上电 → 电脑 `eyepqc run` → 手机登录观看。

## 本版变化

- 固定板端身份与可更新随机状态存入 SD，日常 PC 不注入私钥或 seed。
- 账号登录、自动配对、ML-KEM 握手、定时与手动换钥、视频解密播放。
- 当前首次连接问题按用户反馈标记为已修复。
- 四端新手教程，过时调试报告/一次性脚本清理，示例不含实际部署地址。
- APK 默认空地址、仅系统证书信任，部署 CA 由管理员显式提供。

## 安装前请注意

安装包不包含账号、配对文件、证书、SSH 私钥或板端私钥。全新部署须按教程准备这些材料。
公开 APK 使用 Debug 签名，不是生产签名版；自有 CA 部署应继续使用已有匹配 APP，或按教程用该部署的公开 CA 自行构建。
不要直接用系统信任版覆盖后跳过证书检查。PC 程序尚未商业代码签名。
Board 仅交付源码；BOOT/AMD 生成物分发审查未完成，需在自己的工具环境构建。

功能发布不代表生产安全认证。初始配置端仍须可信；SD 读出/克隆/旧状态回滚不在本版保护范围，没有新增硬件熵。
本轮新包通过软件检查，未自动替换现有部署，其他冷启动、故障和长稳门禁不因此全部通过。
旧 Git 历史与旧 v1.0.0 发布保持不变，隐私清理只覆盖当前源码及本次新附件。
