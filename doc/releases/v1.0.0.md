# EYEPQC v1.0.0 — 开发态 MVP

发布日期：2026-10-21。项目版本与组件版本独立：Windows PC 1.3.2、Android 0.8。
本次是功能基线发布，不是生产安全认证或全部硬件门禁通过。

## 功能范围

- CF7020B / Zynq-7020 + OV5640 JPEG，板端 AES-128-GCM 加密，经 USB Slave 接 Windows PC。
- PC 账号密码登录、本地加盐 scrypt 数据库、WSS 密文转发、可选 SSH 反向公网中转。
- Android 自动获取公开配对、身份认证临时 ML-KEM-512、HKDF/双向 Finished、Tag/重放检查与视频显示。
- 每 30 分钟重新握手、手动换钥、同账号显式接管；不把账号密码或 token 放入 schema2 配对文件。
- SD 开发态程序启动与显式 USB 初始化实现；板端最新镜像仅离线检查通过，尚待实板验收。

第三方许可随 ZIP 提供，转发时不要移除。项目自研部分未指定统一开源许可证，本次未擅自选择许可或更改仓库可见性。

## 运行前提

### Windows PC

安装器不会打包或生成真实账号数据库、公开配对、TLS/SSH 私钥、服务器证书或板端身份。
需要预先准备已有运行材料；安装器可读取当前用户设置，或接受可信旧配置 JSON 来定位这些文件，缺材料会拒绝安装。
全新环境的部署方法与配置参数见 [PC README](https://github.com/fantZach/EYEPQC/blob/v1.0.0/pc/README.md)。
独立 CLI 同样不自带这些文件；它不是绕过初始化的即用版本。

在已经配置好的环境打开新终端：

```powershell
eyepqc --version
eyepqc config show
eyepqc check
eyepqc account list
eyepqc account add --username viewer
eyepqc account passwd --username viewer
```

密码在隐藏提示中输入，不要放在命令行、日志或聊天。运行中的 relay 使用启动时账号快照，
账号变更后按正常流程重启服务生效。不要盲目杀进程或重复启动占用中的端口。
开发态 USB 初始化需显式启用参数并提供受保护的测试身份文件；不要发送给别人或嵌入 EXE/SD。

### Android 与服务器

Android 最低 API 26（Android 8.0），本包版本 0.8，使用 Debug 签名且 `debuggable=true`。
专用公开测试 CA 只在调试变体信任，仍校验地址和有效期；测试 CA 于 **2026-11-12 16:59:03 UTC** 到期。
到期必须准备新的可信开发证书/构建，不能关闭校验。应用默认公网地址只是开发入口，不承诺公共服务可用性。
详情见 [Android 交付说明](https://github.com/fantZach/EYEPQC/blob/v1.0.0/mobile/RELEASE.md)。

服务器端是透明 OpenSSH TCP 中转，不替代 PC 的 TLS/账号认证，也不持有业务视频密钥。
需要自行部署/维护有权限使用的 Linux 服务器，见 [server README](https://github.com/fantZach/EYEPQC/blob/v1.0.0/server/README.md)。
本次发布不连接或变更现有云服务。

## 验证与已知限制

- 历史真实手机播放、重连/手动换钥已有用户反馈约 45 fps；不是当前所有 UI、持续时长或公网性能的完整验收。
- USB 首次 QUERY 曾超时、第二次连接成功。最新 `_6` 候选修正了生成 CH9 CLEAR_HALT 方向 toggle 行为，
  但尚未部署，不能声称现场首次连接问题已修复。不靠无条件重试或跳过认证隐藏问题。
- 本轮验证只覆盖离线测试、APK/PC 产物和板端构建清单，未操作板卡/手机或进行公网长测。
  确切命令和结果见 [发布核验记录](https://github.com/fantZach/EYEPQC/blob/v1.0.0/report/release_v1.0.0.md)。
- G0 自检冷启动不等于 G6 完整视频冷启动；G7 约 50 分钟用户例外不等于满两小时实测。
  故障、完整 G8/G9 等未完成子项仍保留在 [steps](https://github.com/fantZach/EYEPQC/blob/v1.0.0/doc/steps.md)。
- 当前 PC 经 JTAG 或本地明文 USB 提供测试私钥/seed，因此仍是可信调试边界；
  不具备对该 PC 的前向保密，不是生产密钥部署方案。见 [SECURITY](https://github.com/fantZach/EYEPQC/blob/v1.0.0/SECURITY.md)。
- PC 二进制没有商业代码签名或独立杀毒认证；Android 不是生产签名版本。
  不关闭安全软件，不弱化 TLS、账号或协议校验来规避问题。
