# G6：开发态 USB 动态会话（2026-09-29）

CF7020B、P2 OV5640、P4 USB Slave、JTAG。沿用 G4/G5 的 bitstream，
USB 控制通道在实际板卡完成 ML-KEM-512、双方 Finished 和带 MAC 的 START；
视频包使用本次会话派生的 AES-128-GCM Key、32-bit epoch 与单调 64-bit 包序。
主机先验证 Tag 和重放窗口，再组帧、解码、保存。

## 复现

```powershell
$env:EYEPQC_G4_XSA = 'C:/Users/23976/Desktop/WorkingOn/EYEPQC/build/vivado/g4_usb_1/m01.xsa'
$env:EYEPQC_G4_VITIS = 'C:/Users/23976/Desktop/WorkingOn/EYEPQC/build/vitis/g6_repro'
$env:EYEPQC_USB_APP = 'g6_usb'
& 'D:/AmdDesignTools/2026.1/Vitis/bin/vitis.bat' -s prj/build_g4.py
& ./.venv/Scripts/python.exe src/host/g6_board.py --workspace build/vitis/g6_repro --seconds 10 --sessions 2
& ./.venv/Scripts/python.exe src/host/g6_board.py --workspace build/vitis/g6_repro --seconds 5 --sessions 2 --fault-check --reconnect
# G7 实际拔线测试时，重新插好 USB 后复用同次上电的固件，不再 JTAG 重载：
& ./.venv/Scripts/python.exe src/host/g6_board.py --no-jtag --seconds 10 --sessions 1
```

须先按 [M09](m09.md) 生成本机被 Git 忽略的
`board/output/m09/{private.bin,public.bin,public.sha256}`，并保持 JTAG、摄像头和
USB Slave 已连接。脚本自动发现 CDC 端口，每次运行经 JTAG 临时加载 ELF、
测试私钥及 Windows CSPRNG 的新 32-byte 种子；种子临时文件用后删除。
JTAG 只写 ELF 拥有的 DDR mailbox，不写 SD/QSPI。板端消耗并清零 mailbox，
私钥与种子的常驻副本仍在 RAM，故这是**开发态验证**，不是安全部署。
生产版需要板端可信熵源、安全密钥存储/注入，以及私钥访问控制与侧信道评估。
测试 VID/PID `03FD:7020` 也不能用于产品发布。
